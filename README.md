# (ADCO) شركة الإسكندرية للكيماويات والمنظفات
## منظومة المتابعة والتنسيق الميداني المعتمدة (Field Operations Platform)

[![Version](https://img.shields.io/badge/version-2.5.0-success.svg)](./docs/file-structure.md)
[![Architecture](https://img.shields.io/badge/RBAC-3--Tier-blue.svg)](./docs/system-architecture.md)
[![PWA](https://img.shields.io/badge/PWA-Enabled-emerald.svg)](./frontend/manifest.json)
[![Status](https://img.shields.io/badge/Frontend-Modularized-brightgreen.svg)](./docs/file-structure.md)

المنصة الرقمية الموحدة لشركة الإسكندرية للكيماويات والمنظفات (ADCO) لإدارة وتوثيق العمليات الترويجية، ومتابعة عروض المنتجات بالفروع، واحتساب حصص العلامات التجارية ($1/N$)، وتقييم جودة التنفيذ الميداني وفق معايير الجودة المعتمدة (100 نقطة).

---

## 🚀 التشغيل السريع (Local Quick Start)

### تشغيل التطبيق في المتصفح المحلي:
- **نظام ويندوز (Windows):** انقر نقراً مزدوجاً على ملف [`run-app.bat`](./run-app.bat) ليتم فتح المنظومة مباشرة في المتصفح الافتراضي.
- **أي متصفح ويب:** افتح الملف [`frontend/index.html`](./frontend/index.html) مباشرة عبر المتصفح (يدعم بروتوكول `file://` المحلي بالكامل أو عبر أي خادم ويب ثابت مثل Live Server أو Nginx).

## 👥 حسابات الدخول التجريبية الثلاثية (3-Tier RBAC Demo Accounts)

| المستوى الوظيفي | الاسم والرقم الوظيفي | كلمة المرور | نطاق الصلاحيات والرؤية |
|:---|:---|:---|:---|
| **1. منسق ميداني (Coordinator)** | أحمد محمود العبد (`ADCO-101`) | `Pass@1234` | تسجيل الأنشطة، رفع جولات المتابعة، طلب إنهاء النشاط، ورؤية فرعه المسند فقط (فرع سموحة). |
| **2. مشرف منسق (Coordinator Supervisor)** | أيمن عبد الرحمن الروبي (`ADCO-501`) | `Super@2026` | نفس الصلاحيات الميدانية مع نطاق رؤية موسع لكافة فروع العميل المسند في الإسكندرية (فتح الله)، والمنافسة بالرتبة الفضية (#2). |
| **3. مسؤول التسويق (Marketing Manager)** | م. حسام الدين غانم (`ADCO-901`) | `Admin@2026` | إشراف عام شامل على مستوى الجمهورية، تقييم الجولات (100 نقطة)، اعتماد الإنهاء، استعراض الشيتات والتحليلات. |

## 🏗️ الهيكل البرمجي للمشروع (Project Architecture)

```text
adco-field-app/
├── docs/                                       # 📚 مركز التوثيق الشامل لكافة المواصفات
│   ├── endpoints.md                            # عقد الـ API ونماذج DTO
│   ├── file-structure.md                       # دليل ومسؤوليات الملفات
│   ├── system-architecture.md                  # معمارية النظام وتدفق البيانات
│   └── ui-ux-design-guide.md                   # دليل هوية التصميم وتجربة المستخدم
│
├── frontend/                                   # 💻 كود الفرونت إند الموحد (Single Source of Truth)
│   ├── index.html                              # البوابة الرئيسية للواجهة
│   ├── manifest.json                           # ملف تعريف الـ PWA
│   ├── sw.js                                   # مشغل العمليات بدون إنترنت (Service Worker)
│   ├── assets/                                 # أيقونات SVG وصور الشعارات
│   ├── css/                                    # 14 ملف CSS تركيبي ومفصول تماماً
│   ├── pages/                                  # 8 صفحات فرعية للعمليات والمتابعة
│   └── js/                                     # محركات التشغيل ومتحكمات الصفحات (SRP)
│
├── run-app.bat                                 # مشغل المنظومة في بيئة ويندوز المحلية
├── vercel.json                                 # إعدادات النشر السحابي على Vercel
└── README.md                                   # بوابة المشروع التوثيقية
```
